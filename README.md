# Mini-PLM Frontend

React UI for Mini-PLM (Windchill-inspired interface).  
Connects to the Spring Boot backend API.

## Live App
Frontend: https://mini-plm-frontend.onrender.com  
Backend API: https://mini-plm-backend.onrender.com/api

## Tech Stack
- React • JavaScript
- Axios (REST API integration)
- Bootstrap UI
- Render deployment

## Run Locally
```bash
git clone https://github.com/Subhash0910/mini-plm-frontend.git
cd mini-plm-frontend
npm install
npm start
```

App → http://localhost:3000

## Features
- Parts list view
- Create / update / delete parts
- Windchill-style layout
